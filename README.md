## Configuration

Add to your `claude_desktop_config.json` (Claude Desktop) or your MCP client config:

```json
{
  "mcpServers": {
    "sbom-cyclonedx-mcp": {
      "command": "uvx",
      "args": ["sbom-cyclonedx-mcp"]
    }
  }
}
```

Or: `pip install sbom-cyclonedx-mcp` then run the `sbom-cyclonedx-mcp` command (stdio transport).
